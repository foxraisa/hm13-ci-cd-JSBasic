# В данном проекте добавлены решения задач по подготовительному курсу JS («Отус онлайн-образование» 2025 год)

## Урок "Работа с DOM"
** решение написано в 3x файлах workingDOM.js, index.html, styles.css **
Сверстать страницу и подключить к ней файл со скриптом. На странице должны быть три текстовых параграфа, поле ввода и кнопка. Напишите скрипт, который будет выполнять следующие условия:
1.Кнопка скрыта, если в поле ввода нет значения.
2.При клике на кнопку добавляется новый параграф, содержащий текст из поля ввода.
3.*Если параграфов становится больше 5, первый из них удаляется.
 
### Как запустить

1. Установите Node.js с сайта https://nodejs.org/

2. Скачайте файлы проекта в папку

3. Откройте терминал в папке проекта и выполните:
```bash
npm install

Запустите приложение:
npm start

Чтобы запустить тесты:
npm test

Чтобы запустить тесты в режиме наблюдения (автоматически при изменениях):
npm run test:watch

Команды
npm start - запуск для разработки
npm run build - сборка для публикации
npm run dev - сборка без сервера
npm test - запуск тестов
npm run test:watch - тесты в режиме наблюдения


Что проверяют тесты
✅ Кнопка активируется только когда есть текст
✅ Новые параграфы добавляются правильно
✅ Показываются ошибки при неправильном вводе
✅ Счетчик обновляется корректно
✅ Не больше 5 параграфов одновременно
✅ Поле ввода очищается после добавления

Структура проекта
src/index.html - HTML страница
src/script.js - JavaScript код
src/style.css - стили
__tests__/app.test.js - тесты
package.json - настройки проекта
webpack.config.js - настройки сборки
jest.config.js - настройки тестов

## Урок "Массивы"
** решение написано в файле arrays.js **

1.Выведите в консоль сумму всех элементов массива.
